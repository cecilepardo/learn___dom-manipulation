# learn___dom-manipulation

This project was created to practice manipulating the DOM (Document Object Model) in JavaScript.

## Purpose

The goal of this repository is to learn and experiment with:
- selecting elements in the DOM
- modifying content and attributes
- handling events
- dynamically adding and removing elements
- updating the UI based on user interactions

This project is part of my learning process.

## What I practiced

- Selecting elements with `querySelector`
